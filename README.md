# StackPulse

Real-time Stacks monitoring platform with Clarity contracts, a Chainhook-backed server, and a Next.js frontend.

## Quick Start

```bash
npm install
npm --prefix server install
npm --prefix shared install
npm --prefix frontend install
```

## Common Commands

```bash
# Contract tests
npm test

# Contract checks
npm run clarinet:check

# API server
npm --prefix server run dev

# Frontend
npm --prefix frontend run dev
```
